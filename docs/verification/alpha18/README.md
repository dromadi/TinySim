# Alpha.18 — pratinjau dan bukti

Semua gambar memakai renderer, shader, tekstur dan Canvas HUD asli, direkam JVM dan diputar di WebGL. Bukan screenshot Android atau pengukuran FPS HP.

- `mixer-pour.jpg`: molen di posisi tuang, drum berputar, tiga dari delapan petak beton terisi.
- `wreck-impact.jpg`: ayunan pertama telah meruntuhkan tiga balok; puing sedang jatuh dan bola kembali diangkat.
- `yard-finished.jpg`: lantai beton selesai, seluruh bangunan latihan telah menjadi sembilan puing; kedua truk tampak di area selatan baru.
- `keeper-open.jpg`: jembatan dibangun lewat model, penjaga melambai dan kedua palang terangkat.

`results.json`: empat scene GL PASS. `result.json`: tes/lint/metadata APK. Laporan tes XML asli, log build, laporan lint, daftar izin, verifikasi sertifikat dan `adb devices` disimpan di sini. 117 tes lulus, 0 gagal/error/skipped; lint 0 error dan 1 warning landscape. Instrumentation APK hanya dikompilasi. Tidak ada uji langsung HP/emulator.
